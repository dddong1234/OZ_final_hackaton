## 결론

- 확정 우선 후보: 변이 유형 + fold-train hotspot 50
- hotspot 100은 피처가 더 많지만 일관된 추가 이득이 없음
- 최소 유전자 빈도 필터는 단독·결합 모두 기여가 작거나 성능을 낮춤
- 희귀 유전자 열을 제거하기보다 구체적인 반복 변이 피처를 추가하는 편이 유리
- exp_005에서는 모델 파라미터를 변경하지 않고 mutation token 표현만 비교

## 구현 개선

hotspot 열을 DataFrame에 반복 삽입해 발생하던 `PerformanceWarning`을 제거했다.
hotspot 배열을 한 번에 생성한 뒤 `pd.concat(axis=1)`으로 결합한다. 실제 데이터
일부에서 hotspot 100개 출력이 기존 정의와 동일하고 경고·중복·결측이 없음을
확인했다.
